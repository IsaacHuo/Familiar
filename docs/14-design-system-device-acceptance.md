# D 阶段真机验收清单

此表是待所有者确认的验收步骤，不是运行证据。D 阶段实现、静态检查和编译结果见根目录 PLAN.md 与 state/CURRENT.md。未启动 Simulator、未采集真机截图，下面保持未勾选。

## 共用检查条件

- [ ] iOS 18 回退与支持 Liquid Glass 的设备均可完成相同流程。
- [ ] 中英文、深浅色、系统外观跟随均无不可读文本或缺失键。
- [ ] 最大辅助功能字号时可滚动阅读、完整输入和保存；内容不被固定高度截断。
- [ ] VoiceOver 能读出控件用途、选中状态和结果；可分别访问批准、取消、撤销、分享和预览。
- [ ] 降低动态效果时没有持续旋转／闪烁；降低透明度时导航和输入控件有清晰回退。
- [ ] 小屏与键盘展开时，图标触摸区互不重叠，输入、发送、停止和关闭均可触达。
