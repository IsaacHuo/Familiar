# Telegram 参照的全局导航与聊天重构

后续跨页面优化与最新 U0 阻塞修复方向见 [21：全应用 UI 优化总指引](21-telegram-ios-ui-optimization-guide.md)。本文件保留 R0–R6 的设计边界，不将总指引中的候选视为已实现。

所有者于 2026-10-18 授权实施。功能与 UI 研究分别见 [功能研究](research/2026-10-18-telegram-ios-functionality.md)、[UI 研究](research/2026-10-18-telegram-ios-ui.md)。本文件描述目标；当前实施与验证只在根 `PLAN.md` 和 `state/` 记录。

## 信息架构

原生 Tab 顺序 **文件｜聊天｜设置**，启动默认聊天列表。各 Tab 独立导航。聊天详情隐藏 Tab bar，返回列表恢复。

聊天首页包括搜索、最近/项目分类、独立新草稿、归档入口和会话列表。最近包含全部未归档普通/项目会话，置顶优先、活动时间降序、UUID 稳定打平。项目分类只过滤；普通会话保持 project=nil。最近新建普通草稿，项目内新建项目草稿，首次提交成功才创建正式会话。

项目分类可人工排序，最近固定第一；旧项目置顶用于初始顺序，新项目追加，管理页支持创建、编辑、归档。移动会话复用现有文件复制/引用重绑/摘要和授权清理。

## 本地状态与运行

- 新增持久草稿记录：稳定 ID、可选正式会话/Project、正文、UTF-16 选区、技能、已导入附件、更新时间。文字防抖、导航/后台/附件完成/润色应用时保存。附件清理保留所有草稿引用；导入中任务可取消，不跨重启续传。
- 新增列表状态：归档、自动未读回复身份、手动未读、轻量摘要。历史默认已读。完整回复与未读同一终态保存。逐 token、工具活动、润色不计未读。
- 自动已读要求正式详情在前台、未被锁定/遮挡且最新完整回复末尾可见。预览不清未读。角标为未读会话数，归档独立计数且新回复保持归档。
- 根协调器持有会话与唯一前台执行占用；其他会话可阅读、保存草稿，但不能启动新 Agent/润色。状态入口返回正在运行或等待审批的会话。审批仍只在真实输入区执行。
- 文件 Tab 聚合现有 File/FileVersion，显示归属并可筛选；任何操作保留完整 scope。
- 搜索为本地当前分类/全部，区分会话和消息命中，支持原消息定位，归档明确标记。
- 单一当前 SwiftData schema 增加可初始化记录；不引入历史迁移链、不再次业务 reset；旧 store 在副本上验证，失败保持恢复流程。

## 列表与聊天 UI

- 原生 UICollectionView + diffable + UIHostingConfiguration；稳定图形、标题/时间、最多两行预览、项目/置顶/真实状态、未读标记。列表只在保存和运行边界更新，不跟随 token 排序。
- 分类点击与原生横向分页共用选择/进度；保存各分类阅读位置；多选时禁止分页。行操作使用长按和多选。
- 长按冻结最近三条消息的一屏预览，复用生产气泡；不创建 Runtime、不改草稿/已读、不播放媒体；原生预览提交进入同一会话。菜单含打开、置顶、已读、归档、重命名、移动、删除；批量支持已读/归档/删除。
- 抽屉视图、推开手势和布局隔离保存、保持编译；生产无挂载、边缘触摸区或开关。
- 用户右、AI 左；Run 为稳定消息组，文本/工具/文件顺序不变，页脚只出现一次。Markdown/WebKit、代码表格横滑、公式、Mermaid、来源与选择保留。
- 技能左侧独立按钮，不依赖焦点，完全删除 / 触发。菜单收键盘，选择只更新技能，文字/附件/选区不变并恢复焦点。附件图标 paperclip，继续系统相机/照片/文件菜单。
- 发送一次入场，流式转历史保持身份；键盘/菜单/高度更新不得抢阅读位置。统一使用现有 Motion 与可访问性策略。

## AI 编辑器

输入区按钮打开原生 Sheet。翻译（选择语言）、风格（自然/正式/简短/本次自定义要求）、修正三类。默认当前聊天有效模型，可本次另选已配置模型。复用 Provider 与用户凭据；请求只有要求和正文、tools=[]，不进入 Agent、不读取 Memory/历史/附件、不创建聊天 Run。打开不自动请求，完整结果才可应用；不直接发送；应用恢复焦点并可撤销。请求取消、晚到、草稿/会话变化、空/截断结果不能覆盖草稿；与 Agent 共用串行占用。

## 所有者真机验收顺序

本轮到此收口，下一步安排等待所有者反馈；实现及编译证据见根 PLAN.md，以下项目通过前不视为路线验收完成。

1. 冷启动进入聊天，逐一切文件/设置；进入会话隐藏 Tab bar，原生返回恢复列表；从项目详情进聊天再返回，路径正确。
2. 最近/项目点击与横滑、列表滚动、长按预览及菜单、多选、归档与未读角标；预览不清未读，阅读到最新完整回复才已读。
3. 两个新草稿分别输入文字、选择技能、导入附件，返回/切 Tab/重启后分别恢复；发送失败仍保留草稿。
4. 短消息、长 Markdown、代码、宽表格、公式和 Mermaid；检查左右气泡、滚动锚点、键盘升降、浅/深色与大字体。技能选择后文字、选区、附件与焦点正确，回形针打开系统附件菜单。
5. 用自己的 Provider 运行 AI 翻译/风格/修正，检查预览、应用、撤销、取消与错误；结果只回填草稿。回复运行中返回列表/浏览其他会话，再返回原会话查看停止、审批和结果。

记录设备/系统、问题所在页面、复现步骤及截图；先集中修复阻塞和视觉问题，再决定 R6 自动运行验证与后续路线。

## 首页与聊天详情修正（所有者本次真机反馈）

实施范围限定为 UI、输入与消息交互，不修改 Provider、授权、存储 schema 或运行业务。

- 系统三 Tab 保留，删除整个底部 accessory；运行入口移到首页顶部中央。无任务时中央留空，首页不显示“聊天”标题。系统决定紧凑宽度，不缩放或裁切 Tab Bar。
- 分类为完整悬浮玻璃胶囊；列表延伸到导航、分类及底部控件后方，草稿和归档入口进入列表内容流。搜索默认收起，顶部下拉展开，上滑折叠，按真实偏移连续变化并吸附。当前分类单独保存位置；搜索取消恢复之前状态。
- 详情省略号只使用工具栏的一层玻璃；中央模型胶囊关闭系统共享玻璃背景。技能按钮固定 44pt 纯图标，关闭三横线、展开叉号，语义标签保留。
- 输入使用原生 UITextView，共享正文/占位字体和 inset、实际高度与 UTF-16 选区桥接；单行居中，多行顶部对齐。标记文本存在时不重写正文或选区，避免打断中文输入法组合。
- 消息不再常驻复制或重试按钮，改为气泡长按原生菜单；用户消息支持复制/选择文本/现有编辑，完成的 AI 消息支持复制/选择文本/满足安全条件时重试。来源、后续问题和代码块内复制保留。
- 选择文本在原气泡内进行，选择模式暂停消息菜单，并提供完成退出。菜单/选择接入阅读检查状态；只读列表预览不启用消息动作。UI 测试以 `message.completed` 判断终态，不再依赖复制按钮。

所有者最新验证边界：代理只完成指定 arm64 Simulator 的 App 与测试目标编译，不执行测试、启动 Simulator 或截图。真机视觉由所有者负责；以下项目仅供所有者验收：空玻璃条、Tab 宽度、顶栏单层边框、分类透出内容、搜索吸附、输入基线/中文选区、消息长按与原位选择、阅读位置和深浅色/大字体。编译证据见根 PLAN.md，不能视为这些交互已运行通过。
