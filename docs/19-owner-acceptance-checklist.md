# 统一验收清单（所有者一次跑完）

最后更新：2026-10-17。这是所有待验收项的**唯一入口**：按顺序跑完并在每项前打勾。详细步骤与背景见各分册（本文件已经包含最低可执行的检查步骤；分册用于深挖失败原因）。

前置：真机安装当前 main 构建；记录设备型号、iOS 版本、外观、字号、语言、网络。真实 Key 使用非生产测试 Key；测试数据带“Familiar 验收”前缀。认证、流式、工具、写入等真实服务项不得用 fixture 结果勾选。

## 1. 基线冒烟（每轮验收必跑）

- [ ] 冷启动进入对话页：无崩溃；空状态显示建议卡片；顶栏显示当前模型名。
- [ ] 发送「2+3 等于多少」：流式回答正常，无多余工具调用；回答下方复制/分享/重试按钮可用。
- [ ] 长回复生成中上滑阅读旧消息：不被拉回底部；停止后保留已收内容，控件恢复可发送。
- [ ] 断网发送：错误可理解，草稿保留；恢复网络后可重发。
- [ ] 切到后台再回前台、杀掉重开：历史仍在，无重复消息、无残留 spinner。

## 2. P0-联网搜索（S1）

- [ ] 设置 → 搜索服务：保存 Tavily Key → 连接验证通过；换成无效 Key → 明确认证失败，不显示虚假回答。
- [ ] 提问需要最新信息的问题：回答带行内引用角标，展开来源 Sheet 只列实际引用来源，编号与正文一致；点来源可打开。
- [ ] 断网/无结果：如实报错，不伪造来源；保存网页到项目后断网仍可查看已存正文。
- [ ] DeepSeek + Tavily 固定 20 条中英文查询（脚本见 15-s1-search-acceptance.md）：逐条记录通过/失败。

## 3. 普通对话/项目与生命周期（work-scope 切片）

- [ ] 普通对话发送、附图片、生成文件、重启：归属为普通对话；文件只出现在该对话的 Files。
- [ ] 新建议题验证一次性业务重置：旧数据被清空，Keychain/模型与搜索配置/外观偏好保留；第二次启动不再重置；若 store 打不开进入恢复页且不清数据。
- [ ] 创建项目 → 项目聊天发送 → 移入/移出项目：文件随移动复制并可打开，旧范围授权失效；删除项目后聊天转普通且历史文件仍可打开。
- [ ] 删除普通对话：其独有文件与 Workspace 被清理；项目文件不受影响。
- [ ] 抽屉：项目 0/5/6/100 条、普通 20 条以上、置顶去重、展开/收起、查看更多打开完整列表；搜素功能正常。
- [ ] 同 UUID 的 Project/Conversation 隔离：项目里的授权与文件不会出现在普通对话。

## 4. 授权分级与写入（S2a + S2b）

- [ ] 创建提醒：首次出现审批卡，默认选中「始终允许此类」；确认后创建一条。
- [ ] 同 Project 再创建（换时间/标题）：不再询问；切到普通对话再创建：重新询问。
- [ ] 设置 → Approved Actions：能看到「始终允许此类」记录（显示操作标题与时长）；撤销后再次创建会重新询问。
- [ ] 删除提醒 / 取消闹钟：卡片只有「仅这次」，不产生持久授权。
- [ ] 任意已执行写入：活动行出现可撤销回执；点 Undo 后系统对象/文件被撤销，重复点不会二次执行；重启 App 后 EventKit/闹钟写入仍可撤销。
- [ ] 拒绝/取消审批：零写入；拒绝后历史卡显示已跳过。
- [ ] 记忆：开关开启时要求记住偏好 → 无卡片直接写入并出现可撤销回执；撤销后该条消失；设置 → 记忆可见该条；关闭开关后不再写入也不读取。
- [ ] 文档任务中批准一次依赖安装：后续安装不再询问；撤销安装后环境回到安装前（首次安装撤销后为未准备）。
- [ ] MCP：默认未信任时每次调用询问；在 MCP 设置页打开「信任此服务器」后，首次调用出现「始终允许此类」并默认选中；删除服务器后信任被清除。
- [ ] 模型不能自授权：让模型「自己批准」某写入，验证仍会走审批。

## 5. iSH 与文档交付（S4）

- [ ] 首次启动后稍等再发文档任务：活动行出现「正在准备运行环境」，完成后同一条 Run 继续；中途杀 App 重开，再次调用可直接完成准备（标记级恢复）。
- [ ] 生成中文 Word / Excel / PPT / PDF 各一份：Quick Look 打开，中文不乱码，PDF 含粗体。
- [ ] 产物在 Files 中可打开、预览、分享；`file_publish` 失败的文件不显示为成功。
- [ ] 终端：冷准备期间打开终端不被 180 秒 watchdog 误杀；`printf 你好`、`python3 -c 'import docx'`、Ctrl-C、Ctrl-D 正常。
- [ ] Shell 产出损坏的 .docx：文件仍登记但不会被声称「已验证」。
- [ ] 老 Project 无需手动开启即可使用 shell 与文档工具（documents 组默认启用）。
- [ ] `FamiliarDeviceRuntimeTests` + `log stream`；记录冷/热启动耗时与内存峰值。

- [ ] VoiceOver：活动行读出「打开工具结果」；Undo 可读；文件卡可预览/分享；来源 Sheet 行可读。
- [ ] 旧的历史会话（升级前产生）打开不崩溃；无呈现的旧 payload 不显示错误卡片。
- [ ] 侧栏：新对话、搜索、Pinned、Projects 展开、最近对话、底部设置均可点；推开手势与之前一致。
- [ ] 省略号菜单不再有 Memory（设置 → 记忆中也有入口）；Composer 加号打开原生菜单，选择相机/照片/文件正常。
