# Familiar UI 与交互规范

## 唯一视觉基线

对齐 Telegram iOS 固定提交 f1dd7a2；[源码登记](research/telegram-ios-source-map.md) 记录精确文件与阅读深度，[逐项账本](telegram-ios-ui-checklist.md) 管理目标和验收。本规范取代旧抽屉、Beautiful UI 以及 R/U/P 阶段 UI 方案；冲突时遵循本次 Telegram 优先的决定。

采用默认浅深主题及聊天背景，保留 Familiar 名称、图标和产品对象。主题必须来自默认配置与调用链，不从截图猜色。系统公开材质、系统字号、屏幕像素和可访问性是适配依据，不引入私有 API。

## 导航与列表

文件／聊天／设置三个原生 Tab，各自独立导航，默认聊天首页。详情隐藏 Tab，返回恢复分类与位置。Project 映射为聊天分类而非通讯录或频道。已有会话直接呈现；新草稿首次提交成功才创建会话。

聊天行对齐头像、标题、时间、两行摘要、置顶与未读、分隔线、选择态。状态来自真实数据；不增加在线人数、送达勾或虚构用户资料。长按预览使用冻结的最近三条生产消息，复用生产宽度／气泡／时间；保持本地有界只读，不启动Runtime／WebView，不清未读或改草稿。

搜索的入口、展开、取消和恢复按 Telegram 源码核对；本地检索仍保持分类／全部范围、分页和稳定消息定位。任何入口调整同时保留键盘、取消返回及原分类位置。

## 聊天与消息

用户在右、AI 在左，共享气泡轮廓、尾角、合并四角、宽度约束（窄屏减36pt，超过500pt取85%；辅助字号适配）、文字 inset 和主题。相邻用户消息可共享连续边角，但仍保持独立消息 ID；不同 Run 不因同一作者而合并。AI 多块内容保持原顺序与身份，工具和文件不挪到最后。

- 正文、时间、链接、引用和按压色读取同一消息主题；媒体使用对应圆角与独立状态区域。
- 普通多行长正文沿用原生文本，不因字数／换行强制进入WebKit；列表／分隔线／缩进代码、链接、公式、表格与来源块仍保留富文本路径。
- 原生正文按真实 TextKit 末行测量时间；RTL、复杂 Markdown 和引用块保留安全状态行，不覆盖正文。测量与放置复用相同宽度提案，不在放置时强加已测高度；时间尺寸和字号变化使缓存失效。
- 气泡母版必须显式保留capInsets，只拉伸1pt中心；长文与短文使用相同的16/8pt边角和尾角，不将整张掩码放大。
- 长文仍在同一消息宽度中，代码／宽表格／公式／Mermaid 可横滚；不裁切或缩放文字。
- 日期分隔和模型切换使用服务消息样式；模型名和运行状态必须真实。
- 发送只由持久化成功的消息触发一次；历史恢复、逐 token 和行复用不重播。失败或离场释放发送快照。

## 输入与阅读

正文、占位、光标和选区使用同一原生 UITextView 字体及 inset。marked text 期间不外部覆盖；提交前处理中文组合输入。单行基线、六行上限、内部滚动、展开与附件布局共同核对。

发送／语音／停止保持稳定命中区域；附件、Skill 与 AI 润色复用 Telegram 相近入口规则。Skill 只影响下一次 Run；润色为翻译／风格／修正，复用用户 Provider，tools=[]，不读取历史或 Memory，不自动发送；完整结果才可应用并可撤销。

初始历史、最新追随、主动阅读、键盘变化、内容补高、搜索定位和返回恢复拥有明确的阅读状态。用户上滑后不被流式抢回；VoiceOver 暂停自动追随。交互返回开始暂停补偿，取消后按呈现身份恢复。几何不参与已读状态的可观察布局更新。

## 长按、选区与媒体

消息菜单附在实际文本视图，排除链接和内嵌控件命中；退场动作核对菜单实例、消息／正文块／原文／资格，选区另核对代次，旧回调不得消费新菜单动作；原位选择与消息菜单互斥。原生及 WebKit 选区动作冻结会话／消息／正文块身份，菜单退场后才追加草稿，保留原文字、附件与 Skill；审批／澄清占用时不回填。

编辑先建立草稿，取消不改历史。新完整回复保存成功后才替换原尾部，失败仍保留原历史；重试资格继续受外部影响规则约束。

图片实际视口遵循300×380上限／170×74最小尺寸并受父宽约束；极端比例只裁切预览，图库查看原图。附件有正文时由正文承载时间，无正文仅最后显示的附件承载；图片状态白字半透明底、右下6pt。文件使用收／发消息气泡及16/13字体比例，保留真实版本信息与分享。图片按收／发与组内连接使用15/7pt边角；分立图片与正文使用独立气泡规则，0pt同容器连接／媒体尾角／相册拼格仍待后续。只读预览复用顺序、邻接、文件呈现与时间归属，并省略文件打开／分享入口。

图库支持原生缩放、分页、拖拽取消和当前缩略图回归；放大移动优先于退出。仅当前和邻页准备图像，源离屏时淡出。草稿可移除，已发消息与 Files 只读。文档使用 Quick Look，分享捕获准确版本。

## AI 与辅助页面适配

末尾独立文件回执承载唯一终态时间；非文字／非文件结尾以右侧服务时间承载，保持完成标识与块序列。工具活动、回执、Undo、来源及后续问题保留真实契约；不恢复 task_plan、推荐、洞察等已删除的工具面板。Sources 只显示实际引用，后续问题只回填输入框。审批与澄清占用真实输入区，展示等待请求并保持授权范围。

Files 对齐文件列表、筛选、多选及底部操作；每个动作保留 File/Version/Scope。Project、Memory、Run 和环境详情保留原数据及操作，以 Telegram 设置行、分组、Sheet 和渐进披露承载。

设置资料为本机资料，不是账户；Provider 发现、连接验证、外部登录状态分开。验证绑定当前配置身份，修改或失败后清除旧成功。存储统计可取消、如实标记不完整，不自动清理。

## 系统偏好与验证

交互目标至少44pt。中英、深浅色、大字体、粗体、增强对比度、VoiceOver、降低动效／透明度均纳入账本。玻璃用于导航和控件，不给所有消息套玻璃。

每批仅 App 与测试目标 arm64 编译及静态检查；不启动 Simulator、不执行测试、不截图。视觉、手势、真实服务、SQL／CPU／内存和卡死复验由所有者真机证据判断。实现／编译／执行／真机分别记录。
