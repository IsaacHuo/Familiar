- [ ] 每个失败附最短步骤、预期／实际、截图或录屏、对应 Run 的工具与模型记录；不包含密钥、token 或私人文件。

## 第一轮：默认核心路径（F6–F12）

先完成这一轮，再测高级功能。任何数据丢失、拒绝后仍写入、重复操作、无法退出的审批或崩溃都阻止完成验收。

- [ ] **F6 普通聊天与 Harness**：在 Daily Chat 和自建 Project 分别问“2+3 等于多少”和普通概念解释。能直接回答；运行记录无强制 task_plan、无固定规划／验证阶段、无无关工具调用。纯问答可首轮完成，普通聊天不准备 iSH 或发现 MCP。
- [ ] **F6 流式与历史**：请求长回复，生成时上滑阅读旧消息，再回到底部。上滑后不被每个 token 拉回底部；当前回复连续更新，终态无重复正文／工具块。停止后保留已收到内容；切换聊天、退出重开可读历史；新对话／重试／分支不混用别的会话状态。
- [ ] **F6 失败与恢复**：使用独立无效凭据／断网测试，错误可理解，发送控件恢复。区分发送前拒绝（保留草稿）和已提交后的 Provider 失败（保留消息及失败 Run）；纯读失败可重试，已有提交／不确定写入的历史不可盲目重新生成。
- [ ] **F7 Project + 文件**：导入 TXT、Markdown、PDF，提问内容并核对真实文件。切换 Project 后指令和资料边界正确；指定 Project 模型、回到默认、重开历史时顶栏与实际请求一致；模型组用量只展示实际报告值。导入取消不删除源文件；不存在／不支持的文件有明确失败。
- [ ] **F7 发送前保护**：在测试 Project 加入超过上下文预算的资料后发送带文本／文件／图片的草稿。拒绝时草稿与附件仍在，不插入一条已发送消息；减少资料后能重新发送。支持图片的模型收到真实图片；不支持图片时本地识别可取消，失败不消耗草稿。大照片准备期间界面仍可操作，取消后无残留可见消息。
- [ ] **F8 Web**：查询一条需要最新外部信息的问题，核对实际搜索／抓取来源及链接。按需加载 Web 后执行；无结果／断网／页面失败诚实返回。普通抓取不自动增加 Project 资料；点“保存到项目”后有 URL／抓取时间／截断说明，断网也能保存已经取得的正文；重复保存不重复创建资料，重开历史仍可核对来源。
- [ ] **F9 Calendar / Reminders 读取与权限**：查询真实测试日历／提醒列表，结果与系统 App 一致。拒绝系统权限时给出真实不可用原因；不伪称查询成功。批准工具组加载本身不等于批准写入。
- [ ] **F9 写入、拒绝与 Undo**：以测试条目分别批准、拒绝、取消创建。批准只创建一次；拒绝／取消创建零条。核对审批目标、默认“仅这次”和实际回执。完成后退出重开，检查支持撤销的回执可以撤销且重复点击不会再次修改系统；撤销失败／不确定结果不能显示成功。撤销持久授权后，下一次写入重新确认。
- [ ] **F11 Memory**：明确要求记住测试偏好，批准后退出重开确认条目存在；拒绝／取消不产生条目。分别检查 global／project／conversation 作用域，跨项目不泄漏局部记忆；设置中编辑／删除／关自动记忆后，后续聊天遵守实际选择。记忆不能替用户授权工具。保存失败需检查失败回执；没有遇到／执行故障注入时，此分支保持未验收。
- [ ] **F12 文本 Artifact**：要求生成 Markdown／TXT 文件。批准后核对真实正文、回读、Quick Look、系统分享；修改生成独立新版本，旧版字节不变。删除与支持的 Undo 对齐真实文件，缺失文件有错误，不能展示可用成功回执。默认流程不为文本交付准备复杂文档环境。

## 第二轮：系统集成与高级能力（F10 / F13）

只为要验收的能力显式开启高级配置。未启用或不可用时，应说明原因，不自动扩大权限。

- [ ] **F10 地图／天气**：检查真实位置权限、地点／路线坐标、来源和失败。WeatherKit 的成功需要有效签名及服务权限；未配置／被拒绝／断网时不能以估算或其他数据冒充该服务结果。
- [ ] **F13 HTTP MCP**：在测试服务器配置后先做普通聊天，确认不提前发现；请求 MCP 任务后才发现／分页／精确加载选中工具。核对服务器、操作和参数；每次高风险调用审批，拒绝不调用远端。服务器失败／发现超时／取消后能结束 Run，不无限等待。STDIO／OAuth／完整复杂 Schema 不属于本轮已实现能力。
- [ ] **F13 Skill**：选择已安装 Skill 后核对本 Run 指令与工具收窄，下一次未选时不意外沿用；空 allowedTools 不拒绝全部基础能力。测试 HTTPS／GitHub 包导入，只有批准后才安装并绑定 Project，资源可回读；无效包／路径逃逸／超限应拒绝。包安装不执行脚本，不授予设备权限。
- [ ] **F13 iSH / Environment / Shell**：显式开启后检查首次冷准备、再次使用、准备期间取消、命令期间取消、网络开关、输出／时间／资源限制。取消的 Run 不继续启动命令；共享准备可能完成，应与命令取消区分。若环境失败，保持可理解错误且普通聊天可用。
- [ ] **F13 复杂文件**：按实际启用的格式分别生成 DOCX／PDF／XLSX，真实文件可解析／打开／回读／分享，与请求内容相符。只通过其中一种格式，不能勾选其余格式或全部 guest 能力。
- [ ] **语音／外部登录／锁定**：系统语音转写可编辑，拒绝麦克风／语音权限、停止与音频中断有正确状态；只验收实际配置的远程输入／朗读服务。Kimi Code／Codex／OpenRouter 实际登录、取消、回调与刷新分别检查。启用锁定后覆盖已弹出的 sheet，后台／应用切换器不泄漏正文，锁定期间外部分享进入流程延后。
- [ ] **语音音频会话回归**：系统转写与实际配置的远程输入各连续启动／停止至少五次；准备／权限弹窗等待中停止、快速启停、切换聊天或进入后台后，不延迟恢复旧录音。远程转写结束后能再次录音；返回后输入文本不被旧回调覆盖。检查控制台不再出现指向 FamiliarSpeechTranscriber 的主线程 setActive 警告。iOS 18–26 后台 API 路径和 iOS 27 系统异步 API 路径分别验收，有哪种设备就记录哪种，不推断另一种也已通过。
- [ ] **提交中断窗口**：仅在专用测试条目上，审批后结束 App 再打开，核对真实系统状态与 Run journal。中断／不确定操作不能自动重放或宣称已撤销；不具备跨重启续跑。外部动作和本地存储并非原子事务。不能安全复现的存储不足／保存失败分支明确留待故障注入，不人为填满日常设备。

## 第三轮：设计与性能（F14 / E2 / E3）

- [ ] 按 [D 页面详表](14-design-system-device-acceptance.md) 完成 Chat、Composer、Message、Tool Result、Approval、Project、Settings、高级页、输出与详情。覆盖中英、深浅色、最大字号、VoiceOver、降低动态效果／透明度、小屏与键盘；有 iOS 18 设备时检查玻璃回退。
- [ ] **长会话**：在 100 条、300 条真实历史消息下，重复打开、快速上滑、返回底部并流式输出。记录可见停顿、峰值内存及退出会话后是否回落；相同设备／构建／数据重复采样。此项决定是否将现有 eager VStack 改为懒布局，当前未作该决定。
- [ ] **Markdown**：分别使用长代码、宽表格、多张 Mermaid、公式及混合正文。流式补全与终态都检查横向滚动、复制、来源、图表全屏、大字体和外观切换。旧图表异步结果不能覆盖新内容／预览；结束后高度稳定、无内容截断。Node 回归仅覆盖调度，不能代替这里的真实渲染。
- [ ] **主线程工作**：用大照片、接近 25 MiB 的有效文档及较大有效 Skill 包复现准备／导入，记录取消响应和界面停顿；对 Run 初次落盘的附件 hash、上下文图片读取、内置 Skill 初始化和安装持久化分别采样。
- [ ] 需要定位停顿时，以相同交互捕获主线程栈、SwiftUI 更新与内存证据，附 Instruments 导出或截图。记录设备／OS／Debug 或 Release、消息与图表数、文件大小、时间范围；未取得前后对照时不声称 CPU、帧率或内存已改善。收到证据后再决定缓存／懒布局／进一步移出 I/O。

## 自动化测试证据另列

当前 arm64 generic Simulator build-for-testing 仅编译了 App／扩展／测试目标；未运行 iOS 测试或启动 Simulator。Node 的三个异步 Mermaid 调度用例已执行通过，未运行 WebKit／真实 Mermaid。

- [ ] 当前 42 个 Simulator suite 与完整 UI target 实际执行通过，并保存 xcresult；需要另外授权运行 Simulator。
- [ ] 使用 Xcode 为真实设备 build-for-testing 后执行两个 signed-device suite，保存 xcresult。`FamiliarDeviceRuntimeTests` 检查真实 guest；`FamiliarSignedSubmissionTests` 检查带 Keychain 签名环境的图片取消，不证明真实模型或 OCR 通过。

已有签名测试产物时可使用：

```sh
Scripts/run-release-test-suites.sh --device <device-udid> <signed-device-derived-data-path>
```

脚本要求真实非零测试数全部通过；skip、expected failure、缺失计数或中断均不算验收。手工验收与自动化用例执行分别更新 PLAN 的证据，不相互替代。


## 连续回复与 Runtime Card（G9）

- [ ] 普通解释直接流式回复；在同一会话继续要求搜索、读取已上传文件和生成 Markdown 报告，始终使用同一 Familiar／上下文。聊天不显示推理摘要，模型过程正文顺序完整。
- [ ] 重复搜索和多个网页读取默认只出现区段摘要；独立来源去重，调用次数在阶段详情，工具准备／日期成功不另占行。展开只列真实发生的阶段，参数与原始错误默认折叠；重开后的缺失参数明确说明。
- [ ] 部分网页失败后仍能继续回答，折叠摘要轻量提示失败数量；凭据／权限需要处理时保持可见。Shell 失败不显示成功，拒绝单个操作不表示取消整个 Run。
- [ ] 在首字节前、正文中途、并发读取和等待审批／提问时取消；已有正文／结果保持并标记未完成，重开无残留 spinner 或活跃交互。写入途中取消时先核对实际文件／外部动作，journal 不确定提示可见，不能直接重试重复执行。
- [ ] 生成文件卡片在当前回复和历史都能预览／分享，实际缺失／删除／撤销后按钮不可用；复制只取最终回答，过程正文可手动选择复制。
- [ ] 默认折叠，手动展开后执行结束仍保持展开；先滚离底部时不会被抢回，跟随底部时最终正文连续到达。中英、深浅色、大字体、VoiceOver、减少动态效果、小屏／键盘条件均检查。

本切片默认只编译 arm64 Simulator App／扩展／测试目标，不启动 Simulator；上述真实执行、视觉与可访问性仍待所有者记录。

## Functional Convergence 当前真机交付

2026-10-08 当前源码串行 Debug arm64 device build 成功，签名 deep/strict verification 通过；已覆盖安装并正常启动 hwf（com.isaachuo.familiar，无测试参数）。没有清空 App 数据或 Keychain。

终端入口：聊天右上角 More → Terminal → Start。默认关闭本次会话网络；仅当前 Project，前台 180 秒。可直接键盘输入，或用命令字段和 Send；辅助键包括 Esc/Tab/方向键/Ctrl-C/Ctrl-D。HOME 保存在当前 Project，临时目录随会话清理，离开页面或后台停止。手工与 Agent 共用一个 guest，忙时互斥。命令修改没有自动 Undo；人工会话不能授予模型工具授权。

真实 Simulator guest/PTY 回归 4/4 通过；生产 UI worker/AX 自动化超时，用户已要求停止 Simulator 验证。真机手工操作可检查 `printf '你好\n'`、`python3 -c 'print(1+1)'`、长命令 Ctrl-C、Ctrl-D 退出及重新启动；这些尚未由本次安装证明通过。WeatherKit/MusicKit/硬件、强杀恢复、广泛终端和其余 Release Gate 保持独立待验收。
