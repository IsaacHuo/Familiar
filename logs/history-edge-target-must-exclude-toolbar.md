# 历史入口触摸区必须避开顶栏

## 症状

普通字号时点左上角设置会打开历史侧栏；大字体下设置可以打开。生产 UI 回归找不到设置页路由，截图实际停在侧栏。

## 根因

聊天页 30pt 宽、zIndex 100 的透明历史入口从屏幕顶部延伸到正文，覆盖了 safeAreaBar 中部分设置按钮。搜索路由存在，触摸却先被历史入口接收。仅调整 XCTest 的控件类型或等待时间不能修复。

## 修复与验证

透明入口顶部让出 safe-area、44pt 控件高度和顶栏垂直 padding；主内容既有的滑动手势保留。设置按钮使用稳定 accessibility identifier。通过浅/深色、普通/大字号的生产 Chat → Settings → Advanced → Web Search 路径验证，不能只验证大字体或直接实例化设置页。
