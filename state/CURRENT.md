- 已接本地 OSSignposter 和真实持久历史夹具；模型等待、发送准备、历史读取、Markdown 请求与 Shell 准备区分。App RSS 不包含 WebContent，设备基线与前后对照均待采集。

- 上下文／图片／审计哈希、文件复制／校验及网页解码后台准备，回到 MainActor 复核草稿、scope、文件版本和归属。首次 Shell／终端任务复用现有准备流程，根页面不再预热，notPrepared 可编辑 Workspace 偏好。

- 实时 delta 直接进入块级展示缓冲，展示对象以 renderer lease 控制计时；16KiB 以上流式 Markdown 按120ms固定节奏合并，终态 flush，500ms兜底不变。高亮缓存每 renderer 最多32项／约1MiB字符串成本，内存警告清除；DOM 与 Mermaid 内容签名复用。
- 文档代次拒绝旧 JS 消息和完成回调；WebContent 退出最多一次重载，随后原生文本降级。图库缩放页不跨加载 await 强持有自身，离场／析构取消等待；没有设备内存图，未确认泄漏数量变化。
- 发送准备、网页保存、历史加载与重新载入反馈已接；重新载入不重新执行工具。新增回归只编译，最终构建和待验收项见 PLAN；采集方法见 [性能验收](../docs/12-performance-and-reliability.md)。
